# 格雷厄姆低估值工作台 · 静态站

> **A股 / 港股低估值研究工具的一个只读静态快照。**
> 本站是纯静态托管（GitHub Pages），没有后端、没有数据库、没有实时行情。

> [!WARNING]
> **不构成投资建议。** 本站是数据整理与展示，不是荐股工具。
> 数据取自第三方接口，**可能错误、缺失、滞后或随时失效**，不作准确性担保。
> 本站不提供选股建议、不提供买卖时机、也不提供投资组合方案。

---

## 这是什么

一个把「低估值筛选」跑完整条链路之后的**结果快照**：市场温度计、
分市场个股榜、分类型基金榜，以及每个数字的数据来源与已知局限。

站点刻意**不发布**内置策略榜、评分方法论与查询契约清单 —— 那三样在公开
站点上会被读成投资建议，而本项目不提供投资建议。它们在私有引擎侧完整保留。

它不是把某个服务镜像下来，而是把一次完整计算的结果**固化成静态文件**：

```
本地（私有）                          公开（本仓库）
─────────────                        ─────────────
ETL 抓取上游数据                           —
  ↓                                      ↓
SQLite 快照库                          —
  ↓  graham publish（字段白名单投影）
站点 JSON 快照  ──── git push ────→  web/public/data/
                                         ↓  GitHub Actions
                                      静态 HTML（GitHub Pages）
```

**站点是静态的，因为浏览本来就是纯读的** —— 上游配额只在抓取时消耗，
且消耗量与访问量无关。于是"浏览"与"抓取"可以彻底分开：
抓取留在本地，浏览发布成静态文件。

计算引擎（抓取、契约校验、评分、策略、方法论）**不在本仓库**，它留在私有仓库里，
并通过本地 API 与命令行完整提供策略与方法论能力。本仓库只有站点本身。

## 收录范围（请先读这一节）

本站**不是全市场镜像**。为了让站点保持轻量（并守住 GitHub Pages 的体积上限），
快照只发布排名靠前的部分标的：

| 内容 | 收录 | 说明 |
|---|---|---|
| 个股 | **A 股前 50 + 港股前 50** | 按安全边际排序，不是全市场 |
| 基金 | **每个类别前 50** | 偏股混合 / 偏债混合 / 中长期纯债 / 短期纯债 |

因此在筛选器与搜索结果里看到"没有更多了"，是因为**收录到此为止**，
不是因为别处还有。页面在相应位置会标明这一点。

> 个股按市场分别取前 50，而不是全局取前 50：实测全局前 400 名里有 341 条是
> 港股（港股有大量 PB 0.2 的仙股，便宜度得分极高），全局取数会让 A 股几乎消失。

## 数据是什么时候的

`web/public/data/manifest.json` 里记录了快照日、生成时刻与源提交号 ——
页面顶部展示的正是它。本站**不会**自动刷新：更新发生在快照重新发布并被推送时。

## 本地构建

需要 Node 22 与 pnpm 11：

```bash
cd web
pnpm install --frozen-lockfile

# 项目页挂在 /<repo>/ 下，必须设置 basePath
NEXT_PUBLIC_BASE_PATH=/graham-pages pnpm build     # → web/out/

# 本地预览（注意要挂在 basePath 下）
python3 -m http.server 8000 --directory out
```

## 目录结构

```
.github/workflows/pages.yml   构建 + 发布到 GitHub Pages
web/                          站点源码（Next.js 静态导出）
  ├── app/                      路由
  ├── components/               组件
  ├── lib/
  │   ├── snapshot.ts           ★ 数据入口：构建期读 public/data
  │   └── types.ts              快照类型
  ├── public/
  │   ├── .nojekyll             ★ 少了它 Jekyll 会吞掉 _next/
  │   └── data/                 ★ 数据快照（由私有仓库发布而来）
  └── next.config.ts            output: "export" + 快照哨兵
```

**`web/public/data/` 是本站真正的数据源**，请勿在其中手工修改 ——
它会被下一次发布整体覆盖。

## 已知边界

* **财报非 point-in-time**：上游返回重述后数据，故不做财务类回测。
* **港股口径更浅**：财务报告期滞后、港元计价、缺流动比率，只跑简化评分并在页面标注。
* **金融股豁免**：银行/保险的流动比率无经济含义（属分析推论，已在页面如实标注）。
* **部分信号不可用**：如股权质押比例，已列入不可用清单并在页面明示，绝不静默留空。
* **上游语义不稳定**：依赖的自然语言查询接口可能在无预警的情况下改变口径，
  导致部分功能失效或给出错误结论。
