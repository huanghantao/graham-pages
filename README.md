## 本站有什么

| 页面 | 内容 |
|---|---|
| **市场温度计** | 主要指数估值、盈利收益率与债券收益率的比较、市场宽度 |
| **个股** | 本站收录的个股按安全边际排序，可按市场、行业、成交额与动量筛选 |
| **基金** | 多因子评分，四类分别成榜 —— 分数只在**同类内**可比 |
| **数据可信度** | 契约校验结论与已知不可用信号 |

每个数字都可溯源到具体查询，抓取的解析记录公开在「数据可信度」页。

## 收录范围（请先读这一节）

本站**不是全市场镜像**，只发布排名靠前的部分标的：

| 内容 | 收录 | 说明 |
|---|---|---|
| 个股 | **A 股前 100 + 港股前 100** | 按安全边际排序，不是全市场 |
| 基金 | **每个类别前 50** | 偏股混合 / 偏债混合 / 中长期纯债 / 短期纯债 |

因此在筛选器与搜索结果里看到「没有更多了」，是因为**收录到此为止**，
不是因为别处还有。页面在相应位置会标明这一点。

个股按市场分别取前 100，而不是全局取前 100 —— 否则 A 股在榜上几乎会消失。

## 数据时效

页面顶部展示**快照日**。本站不会自动刷新：内容在发布时一次生成，
不随访问更新，也不是实时行情。

## 已知边界

* **财报非 point-in-time**：数据源返回重述后数据，故不做财务类回测。
* **港股口径更浅**：财务报告期滞后、港元计价、缺流动比率，只跑简化评分并在页面标注。
* **金融股豁免**：银行/保险的流动比率无经济含义（属分析推论，已在页面如实标注）。
* **部分信号不可用**：如股权质押比例，已列入不可用清单并在页面明示，绝不静默留空。
* **口径可能变化**：第三方数据源可能在无预警的情况下改变口径，导致部分内容失效
  或给出错误结论。

## 本地构建

需要 Node 22 与 pnpm 11：

```bash
cd web
pnpm install --frozen-lockfile

# 项目页挂在 /graham-pages/ 下，必须设置 basePath
NEXT_PUBLIC_BASE_PATH=/graham-pages pnpm build     # → web/out/

# 本地预览（同样要挂在 basePath 下）
python3 -m http.server 8000 --directory out
```
